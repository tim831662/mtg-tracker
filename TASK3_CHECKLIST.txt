QUICK START
================================================================================

1. Set up PostgreSQL:
   docker compose up -d db
   (or install locally and create database)

2. Apply migration:
   uv run alembic upgrade head

3. Import sample data:
   uv run python -m mtg_tracker.importers.tournaments \
     database/seeds/sample_tournament_data.json

4. Verify in database:
   psql -h localhost -U mtg_user -d mtg_tracker
   SELECT * FROM tournaments;

5. Run examples:
   uv run python examples.py 1  # Import tournaments
   uv run python examples.py 2  # Query tournaments
   # ... (examples 1-10)

================================================================================
TROUBLESHOOTING
================================================================================

Q: Database connection fails
A: Check PostgreSQL is running and DATABASE_URL in .env is correct

Q: Migration fails
A: Run alembic upgrade head after creating database

Q: Importer says "already exists"
A: This is normal - idempotent imports skip duplicates

Q: Card not found warning
A: Check card_id values in JSON match card IDs in cards list

Q: No JSON files found
A: Ensure .json extension or path points to directory with JSON files

Q: Import hangs
A: Check PostgreSQL logs or press Ctrl+C and check DATABASE_URL
